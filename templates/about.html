Implemented Decision-Support Methodology

Phase 1
1. Patient Assessment
User submits demographics and selects presenting symptoms from the validated 132-symptom catalog.
Phase 2
2. Server-Side Validation
Inputs are rigorously validated against boundaries. At least one recognized clinical symptom is required.
Phase 3
3. Feature Preparation
Symptom keys are mapped into the exact 132-dimension binary indicator vector matching model training order.
Phase 4
4. Model Inference
The selected model (Random Forest or Linear SVC) executes multiclass inference to yield predicted class index.
Phase 5
5. Label Decoding
The fitted LabelEncoder translates class integer (0–40) into the canonical medical condition name.
Phase 6
6. Knowledge Lookup
Rule-based service retrieves condition overview, educational medicine info, precautions, diets, and lifestyle guidance.

Trained Machine-Learning Models

Random Forest Classifier

rf.pkl

An ensemble learning method constructing 100 randomized decision trees during training. It outputs the class selected by the majority of trees.

  • Algorithm Type: RandomForestClassifier
  • Number of Estimators: 100 trees
  • Input Dimensionality: 132 binary features
  • Output Target Classes: 41 disease classes
  • Probability Estimates: Supported (Tree voting)

Linear SVC

svc.pkl

A Support Vector Classifier configured with a linear kernel: SVC(kernel='linear'). Maximizes margin separation between classes.

  • Algorithm Type: SVC(kernel='linear')
  • Kernel: Linear (Not RBF)
  • Input Dimensionality: 132 binary features
  • Output Target Classes: 41 disease classes
  • Probability Estimates: Not available (uncalibrated)

Knowledge-Based / Rule-Based Recommendation Architecture

The V1 recommendation system operates via a deterministic, rule-based clinical knowledge mapping pipeline. Upon decoding the predicted condition, the system cross-references structured CSV knowledge bases:

diseases.csv

41 disease overviews & clinical descriptions.

medicines.csv

205 educational medication literature entries.

precautions.csv

162 recommended preventive clinical precautions.

diets.csv

205 nutritional & dietary recommendations.

lifestyle.csv

409 supportive workout & lifestyle guidance records.

AI & Recommendation Research Preview

Future Architectural Roadmap

The following advanced modules are planned for future research iterations. In adherence to strict product transparency, only the verified Random Forest, Linear SVC, and rule-based recommendation systems are active in V1.

Future Extension
1. Content-Based TF-IDF Filtering
Vectorization of symptom descriptions using TF-IDF and Cosine Similarity to recommend non-obvious cross-domain medical interventions.
Future Extension
2. Collaborative Filtering
Matrix Factorization (SVD) across anonymized user interaction matrices to identify lifestyle habits that yielded high perceived efficacy.
Future Extension
3. Hybrid Recommendation Engine
Ensemble weighting combining content-based semantic matching with collaborative utility rankings.
Future Extension
4. Context-Aware Personalization
Dynamic multi-dimensional context modeling factoring in user age, vitals trends, previous health history, and seasonality.
Future Extension
5. NLP & Sentiment Analysis
Transformer-based sentiment classification on user recommendation feedback to detect adverse response signals.
Future Extension
6. Biomedical Knowledge Graphs
Graph-based ontological querying connecting symptoms, disease phenotypes, pharmacological agents, and clinical trials.
